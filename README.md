# EvoTempo

Covariant evolutionary tempo (CET) models for phylogenetics: an implementation of the model of
Budd & Mann (2025, *Systematic Biology* 74:917-934, doi:[10.1093/sysbio/syaf020](https://doi.org/10.1093/sysbio/syaf020)),
in which a heritable log-tempo scales speciation, extinction and character change.

EvoTempo provides a discretized-tempo (dCET) formulation, numerical solutions for extinction
probabilities with extant and fossil sampling, diversity moments and tempo distributions, and exact
forward simulators. Data-augmented Bayesian inference is in development.
